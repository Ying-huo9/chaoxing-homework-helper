# 超星作业抓取助手：用户使用说明

## 本地模式

1. 打开程序，在“本地模式”中点击“选择文件夹”。
2. 选择包含 `.mht` 或 `.mhtml` 作业页面的目录。
3. 按需开启“下载并嵌入图片”，并填写课程、班级和姓名。
4. 点击“开始处理”。
5. 处理完成后，在所选目录的 `产出文件` 子目录中查看 Word、JSON 和文本结果。

## 在线模式

1. 程序会检测系统 Chrome、Microsoft Edge 以及程序目录 `browser` 中的便携 Chromium。
2. 选择浏览器，输入超星账号和密码，然后点击“登录并读取课程”。
3. 如果出现验证码，请在弹出的浏览器中手动完成，再回到程序点击“我已完成”。
4. 使用“作业 / 章节练习”切换内容类型，然后进入一门课程。
5. 读取内容列表后点击“开始抓取”。完成后可返回课程列表继续处理其他课程。
6. 默认结果保存在程序所在目录，也可以通过“保存位置”选择其他目录。

在线抓取会保存原始 MHTML，并生成 Word、JSON 和易读文本。章节练习单独保存在 `课程名\章节练习` 中，不会覆盖作业结果。

## 浏览器行为

- 关闭“始终显示浏览器”时，浏览器会在登录成功后隐藏，并在后台完成抓取。
- 登录失效或需要验证时，浏览器会重新显示。
- 如果受控浏览器被手动关闭，程序会清除当前登录状态；再次登录会重新启动浏览器。
- 受控浏览器数据保存在程序目录的 `chrome` 子目录，WebView 数据保存在 `webview_data` 子目录。

## 设置与凭据

- 模式、主题、浏览器选择、导出选项和保存位置会写入程序目录的 `settings.json`。
- 只有开启“记住账号和密码”时才会保存登录凭据。
- 密码使用 Windows 当前用户凭据加密，`settings.json` 中不保存明文密码。
- 关闭“记住账号和密码”会清除已保存的凭据。

## 安全提醒

不要分享 `settings.json`、`chrome`、`webview_data`、日志、MHTML 网页快照或课程产出文件。如果旧脚本中曾写入明文密码，请立即修改该密码。
